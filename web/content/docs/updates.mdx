Codync has three parts that update separately: the desktop app, the host that runs your bots, and the iPhone app. On macOS and Windows the host ships inside the desktop app and updates with it. On Linux, and on any computer where you installed only the host, the host updates on its own. The iPhone app comes from the App Store.

## The desktop app

The desktop app checks for a new release every day, downloads it, and installs it when you're not using the computer. Both are on by default.

You'll find the update settings in two places:

- **Settings → Updates** in the chat window.
- **Settings → Updates** in the menu bar (macOS) or tray (Windows, Linux) menu.

Both offer the same controls:

| Control | What it does |
| --- | --- |
| **Check for updates** | Checks now. When a release is found, the button reads **Update to** and the version; choose it to download. |
| **Restart to update** | Appears once the release is downloaded. Restarts Codync into the new version. |
| **Automatically check for updates** | The daily check. |
| **Automatically download and install** | Downloads releases on its own and installs them when Codync is idle. |

While a release is available, an **Update** button also appears in the chat window's sidebar. One click downloads it (a ring shows the progress, and Codync stays usable) and restarts into it.

A finished download never quits the app by itself. Automatic installation waits until no Codync window is in front, you haven't used the keyboard or mouse for ten minutes, and no bot is working. A downloaded update also installs when you quit Codync.

On macOS and Windows, updating the app also updates this computer's host: the app stops the host, installs, and starts the new one. If you installed the Mac app with Homebrew, it still updates itself this way.

## The host on its own

On Linux, and on a Mac or server where you installed only `codync-host`, the host updates separately from any app.

- **Installed with the install script** and running as the background service: the host updates itself. It checks once a day while no bot is working, checks that the download is signed, and keeps your data. If the new version doesn't start, it puts the previous one back.
- **Installed with Homebrew:** run `brew upgrade leepokai/codync/codync-host`, then `codync-host install`.
- **Re-running the install script** also upgrades the host and restarts its service.

To check or update by hand:

```sh
codync-host update --check     # is there a newer release?
codync-host update             # install it now
codync-host update --status    # progress of an update
codync-host update --auto off  # turn automatic updates off (on to turn them back on)
```

A manual update won't interrupt a bot that's working unless you add `--force`; interrupted bots pick up their sessions again. In the terminal UI, press `^k` and choose **Check for updates**.

## The iPhone app

The iPhone app updates through the App Store. Every iPhone release goes through Apple's App Review first, so the App Store version can be a day or more behind the desktop app and the host. When a newer version is out, a card at the top of the bot list tells you which version is available, with an **Update** button that opens the App Store. You can dismiss it.

Your computer accounts for the review delay: a computer update that needs a newer iPhone app isn't offered to computers until that iPhone version is in the App Store.

## When the phone and computer versions don't match

Each side knows the oldest version of the other side it still works with. When one side is too old, you see a notice above that computer's bots and in place of the message box, and the computer's status reads **Needs update**. Your chats stay safe on the computer, and drafts are kept. Once the older side is updated, the notice goes away on its own.

| Notice | What to do |
| --- | --- |
| **Update this app** | The app you're using is too old for that computer. On the iPhone, **Update Codync** opens the App Store; if the version you need is still in App Store review, the button stays greyed out until it's available. In the desktop app, use the update button on the notice. |
| **Update Codync on** and the computer's name | The computer's host is too old for this app. The notice says how: on a Mac, open Codync there and check for updates; on Linux, run `codync-host update` there. For the computer the desktop app runs on (macOS and Windows), the notice has a button that updates it. |

In the terminal UI, the status line shows **needs update** with the reason, and sending is blocked until you update.

## If an update fails

1. Quit Codync completely (on macOS, **Codync → Quit Codync**, not just the window's close button) and open it again. A downloaded update may finish installing when the old app exits. Check the version in **Settings → Updates**.
2. If it still fails, reinstall the app from the [latest release](https://github.com/leepokai/Codync/releases/latest) and keep your data.

To reinstall the Mac app:

```sh
# 1. Quit Codync, then remove its background host service (your bots and keys stay):
/Applications/Codync.app/Contents/Resources/codync-host uninstall
# 2. Move Codync.app to the Trash, then install the new one from codync-macos.dmg.
# 3. Open Codync. It sets up the host again. If the host stays stopped:
/Applications/Codync.app/Contents/Resources/codync-host install
```

With Homebrew, quit Codync and run `brew reinstall --cask leepokai/codync/codync`. On Linux, replace the app the way you installed it, and update the host with `codync-host update`.

> **Note:** Don't use **Reset all data…**, delete `~/.codync`, or run a cleanup tool to fix an update. Those erase your bots and the computer's identity, and every phone has to pair again.

## Uninstalling

### On a computer

1. Remove the background host service: in the menu bar or tray menu choose **Settings → Uninstall host service**, or run `codync-host uninstall`. This keeps your data.
2. Quit Codync and remove the app the usual way for your system. With Homebrew: `brew uninstall --cask leepokai/codync/codync` for the app, or `brew uninstall leepokai/codync/codync-host` for the host. A host from the install script lives in `~/.local/bin`; delete `codync-host` there (on Linux also `codync-screen` and `cua-driver`).

`~/.codync` (on Windows, `.codync` in your user folder) holds your bots, conversations, routines, memory and the computer's identity. It stays after you uninstall. Delete it to remove all of it.

To erase everything from the desktop app in one step, choose **Settings → Reset all data…** in the menu bar or tray menu. It removes the computer from your account, revokes every paired device, signs you out, uninstalls the host, deletes its data and the app's settings, and restarts Codync at the welcome screen. With Homebrew, `brew uninstall --zap --cask leepokai/codync/codync` also deletes `~/.codync` and the app's settings.

### On the iPhone

In **Computers & settings**, remove a computer, or choose **Start over** to sign out and forget every computer. Deleting the app removes its cache. Your computers keep their bots and chats either way.
