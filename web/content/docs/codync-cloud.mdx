Codync Cloud runs a Linux computer for your bots on your own account with a cloud provider: **Boat** (in the EU) or **InstaBox** (in the US). Use it when no computer of yours stays on, or to give bots a machine of their own. Codync charges nothing for it; the provider bills your account under its own plan. Codync Cloud is a **beta** feature.

It needs a free Codync account (Apple, Google or GitHub). Every app reaches a cloud computer like any other computer in your account: the iPhone and Android apps, and the desktop app while you're using its window (so the cloud computer can still sleep when you aren't).

## Start a cloud computer

1. Open **Manage computers** on the iPhone or Android (tap the connection status at the top of the Bots tab), or Settings → **Computers** in the desktop app, and in the **Codync Cloud** section choose **+**.
2. Pick the provider. Each one shows where it runs and what it costs: Boat from $20 a month, InstaBox with a free plan that includes one machine (4 vCPU, 8 GiB).
3. Without a key there yet, **Connect** walks you through making one: the steps on the provider's site, **Open** to go there, then paste the key. It's checked with the provider before it's saved. **Use the command line instead** shows the same steps as commands to copy.
4. Name the cloud computer and choose **Create**. It shows "Preparing your cloud computer…" for a minute or two, then appears under its name with its own Codync bot.

Setting up the iPhone or Android app for the first time, signed in, you can start one right there instead of installing Codync on a computer: **Start a cloud computer** on the first page of setup opens the same steps. Setup then waits on **Starting your cloud computer** until it's ready and goes on to your bots; **Skip** goes on without waiting and **Back** returns to setup, and either way the cloud computer shows up by itself once it's ready.

Each account can have up to three cloud computers, on either provider. A provider's key stays while a cloud computer runs there. To replace it, open the provider's **⋯** in **New cloud computer** (or the cloud computer's **⋯** menu) and choose its API key; **Remove key** appears there once no cloud computer uses it.

## Its screen

A cloud computer has a desktop of its own (Linux with Xfce, 1920×1080). Watch and control it from the iPhone or
Android (**Screen** on the computer in **Manage computers**, or **Computer** in a chat) or from the desktop app
(**Screen** on the computer's heading in the sidebar), or watch it on the **Computer** tab of any of its bots' details, and turn on **Use the computer** for a bot to let it open apps
and click and type there. The desktop runs as the same user as your bots, without sudo. It isn't the provider's own
desktop (InstaBox's **Computer** tab shows that one, not this).

The picture usually reaches you through Cloudflare's TURN service, encrypted end to end, at up to 4 Mbps and 30 fps.
Cloud computers made before this feature have no desktop; delete and make the cloud computer again to get one.

## Sleep and wake

A cloud computer goes to sleep while its bots have nothing to do, so it doesn't run up your provider's bill. It shows "Sleeping · wakes when you message", and it wakes when you message one of its bots, when a routine is due, when a [follow-up](/docs/conversations#follow-ups) a bot set is due or when a webhook arrives. Waking takes a few seconds, longer after a long sleep; meanwhile it shows "Waking the computer…", and a text message you send from the iPhone or Android app waits for it.

## Your keys

- **The provider key** is stored encrypted, only for your account, and never shown again: the apps show its last four characters.
- **What Codync does with it:** Codync's service opens the key to create your cloud computers, put them to sleep, wake them and delete them. A Boat key is limited to its `codync` environment and can't run commands on or read a running machine. An InstaBox key reaches every machine in its workspace and can run commands on them (that's how Codync installs the host there), so make the key in a workspace you use only for Codync.
- **On the cloud computer**, your bots and their agents run as a user without sudo. Anthropic, OpenAI and Gemini API keys and voice keys you save there go through a keeper: the bots can use them but not read them. Other agent keys, connector settings and your agents' own sign-ins (Claude Code's or Codex's login) stay readable to the agents, as on any computer.
- **The provider runs the hardware**, so it can in principle read a running machine's memory and files. Boat documents no encryption at rest for its disks, and its snapshots may be stored outside the EU.

## Rename, snapshots and delete

From the cloud computer's **⋯** menu:

- **Rename…** changes its name in every app.
- **Delete snapshots** erases the earlier states the provider keeps of the computer (where it keeps any), while it's awake.
- **Delete cloud computer** deletes the machine at the provider, with its bots and files.
